소방설비 연동설정 방재실 수신기 조작반 기준

방재실 화재수신기 연동정지(출력차단) 조작반의 버튼 명칭과 배열을 그대로 옮겼습니다. 버튼을 누르면 그 설비에 연동정지가 걸려(적색) 화재신호가 와도 동작하지 않고, 다시 누르면 정상연동(녹색)으로 돌아옵니다. 프리액션과 드렌처는 조작반 버튼이 하나로 묶여 있어 함께 잡히고, 방화셔터도 1·2차 기동이 한 버튼입니다. 소화설비(소화펌프)는 연동정지를 이미 해제해 상시 정상운영 중이므로 정지할 수 없도록 잠가 두었습니다.

화면 상단의 단계 버튼으로 1단계 야간 현행(23:00~08:00) → 2단계 야간 확대(4대설비만 연동정지) → 3단계 주간 영업시간 확대(08:00~23:00) → 4단계 전 설비 정상화 순서를 그대로 불러올 수 있습니다. 2·3단계는 연동정지 설비 구성(방화셔터 · 프리액션/드렌처 · 거실제연 · 공조대표화재)이 같고 적용 시간대만 다릅니다.

음향송출줄 🔇 브라우저가 소리를 막고 있습니다 — 화면을 한 번 누르면 송출됩니다 주경종·지구경종·비상방송은 연동정지가 없으면 화재신호와 동시에 자동 송출되고, 연동정지를 걸면 멈춥니다. 싸이렌(유수검지장치·가스계 연동) 구동 시 지구경종도 함께 명동합니다. 비상방송(화재시 안내방송)은 실제 녹음(사이렌 5초+멘트+사이렌 5초)을 다른 방송보다 높은 음량으로 반복 송출해 구분됩니다. 안내방송 3종은 [송출]을 누를 때만 나갑니다. [복구]는 화재신호를 발생 전 평상시 감시상태로 되돌립니다.

비화재보 SOP(같은 시간에 사람이 해야 하는 일) — 소방청고시 제2023-37호 《소방시설 폐쇄·차단 시 행동요령 등에 관한 고시》 기준

설비 연동은 수초 안에 끝납니다. 아래 시간은 그 뒤로 경종이 계속 울리는 상태에서 흘러갑니다.

  1. T+0초화재신호 수신. 발신 주소·동·층과 함께 입력설비 종류를 먼저 확인합니다. 일반 자탐감지기인지, 셔터·거실제연·프리액션 전용 감지기인지에 따라 대응이 달라집니다.
  2. T+30초 이내1차 안내방송. 비화재보로 단정하지 말고 확인 중임을 알리는 문안을 사용합니다.
  3. T+5~8분현장 확인 완료. 이 구간 내내 경종은 계속 울리고 민원 전화가 들어옵니다.
  4. 확인 후화재 아님 확인 → 재실자 안내 → 수신기 화재경보 복구 → 비화재보 방지조치. 소방청고시 제2023-37호 제3조제5호.

확인이 필요한 항목

  • 경보구역의 동(棟) 범위 — 층 범위는 발화층 및 직상 4개층 우선경보(NFTC 203 2.5.1.2) 적용. 같은 층에서 A·B동 / C·D동 그룹인지 4개동 일괄인지는 층별 확인 필요 (현재 3~7층 동 그룹, 8층 이상 동별 독립으로 가정).
  • 공조대표화재의 AHU 묶음 범위 — 어느 감지기가 어느 AHU를 정지시키는지 계통도 대조 필요. 묶음 범위에 따라 피해등급 상향 가능.
  • 설비자동제어(판매·마트) 수동복구 필요 여부 — 자동복구 불가 시 AHU 재기동 소요 증가.
  • 거실제연·전실제연 수동조작함 조작 시 화재신호 성립 여부 — 현재는 설비만 기동하고 경보는 미발생으로 구현.
  • 거실제연 수동조작함(SVP)의 셔터 연동 여부 — 거실제연 감지기(자동)는 셔터 1차 연동을 반영했으나, 수동조작함은 사람이 직접 조작하는 계통이라 셔터 자동연동에서 제외했습니다. 실제로 수동조작 시에도 셔터가 연동되는지 확인 필요.
  • 발신기 신호의 방화셔터 연동 여부 — 일반 자탐 화재신호와 동일하게 처리되는지 미확인.
  • 주차장 패시브휀 — A·B구역 배기 / C·D구역 급기 교대 기동의 연동정지 포함 여부 미확인.
  • 설비별 지연시간 — 실제 지연초 미상이라 순서(Step)만 표시. 실동시험 실측 필요.
  • 조작반 버튼과 출력설비의 대응 — 가스출력은 가스계 약제방출·해당구역 공조정지/댐퍼폐쇄로, 제연댐퍼·제연급기휀·제연배기휀은 거실제연 계통으로, 전실댐퍼·전실급기휀·전실배기휀은 전실제연 계통으로 대응시켰습니다. 실제 결선 기준 확인 필요.
  • 미반영 출력(회색 버튼) — 제연커텐·자동문·대표화재·조명제어·출입통제·속보기·에어컨정지·미디어·A/B출력은 설치 여부와 연동조건이 확인되지 않아 연동로직에서 제외했습니다. 확인 후 반영 필요.
아날로그 임계값: 연기 예비경보 15% / 화재점 17%, 열 예비경보 60℃ / 화재점 80℃ (GFS F3G). 경보방식: 발화층 및 직상 4개층 우선경보 — 지상 2층 이상 발화 시 발화층+직상 4개층, 1층 발화 시 발화층+직상 4개층+지하 전층, 지하층 발화 시 발화층+직상층+기타 지하 전층. 방화셔터 1차기동 출력범위: 지상 3~11층·지하 3~7층 해당 셔터 개별 / 지상 1~2층 동 그룹 / 지하 1~2층 전동 일괄, 2차기동은 전 층 해당 셔터 개별. 싸이렌은 자탐 화재신호 연동 출력이 아니며, 유수검지장치(알람밸브·프리액션·드렌처) 발신 시 또는 가스계 소화설비 기동 시에만 동작합니다 — 자탐 지구음향장치는 지구경종입니다. 「소방설비 연동설정」 칸의 버튼 명칭·배열은 방재실 화재수신기 연동정지(출력차단) 조작반 실물 기준이며, 소화설비(소화펌프)는 연동정지를 해제해 상시 정상운영 중이므로 정지 조작 대상에서 제외했습니다. 교육용 재현이며 실제 동작 시간과 다를 수 있습니다.
