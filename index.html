Firebase 연결

연결하면 여러 사람이 같은 자료를 보고, 수정 내용이 바로 공유됩니다. fire-inspection-dash 설정이 이미 들어 있으니 칸을 비운 채 눌러도 됩니다.

사진 저장 위치

사진은 용량이 커서 문서와 따로 보관합니다. 상반기 기준 1,228장이 압축 후 약 11MB입니다.

드라이브에서 폴더를 열었을 때 주소 /folders/ 뒤의 문자열입니다.
업로드할 때 자동으로 줄여서 저장합니다.

구축 절차

GitHub Pages로 공개하고 Firebase로 자료를 공유하는 순서입니다.

  1. GitHub에 저장소를 만들고 이 index.html을 올립니다.
  2. 저장소 Settings → Pages에서 main / root를 선택해 공개합니다.
  3. Firebase 콘솔에서 프로젝트를 만들고 Firestore를 asia-northeast3(서울)로 생성합니다.
  4. 프로젝트 설정 → 웹 앱 추가에서 나온 firebaseConfig를 위 칸에 붙여넣고 연결합니다.
  5. Authentication → 익명을 사용 설정하고, 보안 규칙을 함께 드린 firestore.rules로 교체합니다.
  6. 사진을 Drive에 둘 경우 공유 폴더를 만들고 폴더 ID를 위에 입력합니다.
